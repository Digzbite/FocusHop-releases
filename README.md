# FocusHop

FocusHop is proprietary macOS software by DigzBite GmbH. This repository provides public downloads, release notes, and issue tracking; application source code is private.

- [Download FocusHop and read release notes](https://github.com/Digzbite/FocusHop-releases/releases)
- [Report a bug or request a feature](https://github.com/Digzbite/FocusHop-releases/issues/new/choose)
- [Visit DigzBite](https://digzbite.de)

Requires macOS 14 or later. Native glass effects require macOS 26 or later. FocusHop costs EUR 2.99 per month plus applicable tax, with a seven-day trial through hosted checkout.

No application download has been published yet. Release assets will appear on the Releases page when available.

When reporting an issue, include your FocusHop version, macOS version, and steps to reproduce the problem. Remove license keys, personal information, and other secrets from reports, screenshots, and logs.
